================================================================================
DEVELOPER NOTES
================================================================================

1. The project uses Next.js 16 App Router, so:
   - Routes are in app/api/ directory
   - Each route.ts file exports HTTP method functions
   - Params are async (use await params)

2. Authentication flow:
   - Client sends credentials to /api/auth/login or /api/auth/signup
   - Server returns JWT token
   - Client includes token in Authorization header: "Bearer TOKEN"
   - Protected routes use requireAuth() middleware

3. Database transactions:
   - Use transaction() helper for multi-step operations
   - Automatic rollback on errors
   - Always release connections

4. Error handling:
   - Zod for request validation
   - Try-catch in all route handlers
   - Specific HTTP status codes
   - User-friendly error messages
